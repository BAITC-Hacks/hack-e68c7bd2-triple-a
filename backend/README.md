# Backend Shabyt

Из корня проекта: `python -m uvicorn main:app --app-dir backend --reload`.
Установка: `python -m pip install -r backend/requirements.txt`. Нужен Python 3.11+.
Проще в Windows использовать корневой `START_WINDOWS.bat`; активация окружения не требуется.

## Маршруты

`GET /health`, `GET /catalog/meta`, `POST /search`. Для frontend есть те же маршруты с префиксом `/api`. Документация — `/docs`.
При наличии `frontend/dist/index.html` `/` раздаёт готовый сайт. Без сборки `/` перенаправляет на `/docs`.

```json
{"city":"Алматы","event_date":"2026-11-14","event_type":"свадьба","category":"Фотограф","budget_kzt":300000,"duration_hours":null,"language":null}
```

Дата строго YYYY-MM-DD, только 2026-09-23 — 2026-12-31. Бюджет и заданная длительность — положительные JSON-целые; строки, bool и дроби не приводятся молча. Неизвестные поля запрещены. Пустой язык означает отсутствие требования. `wedding` поддерживается как алиас к `свадьба` для совместимости старого примера контракта.

Каталог загружается из `backend/data/hackathon-dataset-anonymized.jsonl` + `synthetic_profiles.jsonl`. Пути независимы от текущей папки. Дубли ID и отсутствующий календарь — ошибки данных, не доступные подрядчики. При повреждённом каталоге API выдаёт контролируемый 503.

Город и категория сначала ограничивают исходный каталог. Затем проверяются формат, бюджет, занятость, язык и длительность. `max_hours=null` не отсекается по часам. «Зарубежье» не подмешивается в местные результаты. Сортировка прежняя: близость цены к бюджету, языковой/словесный бонус, ID для стабильности. Максимум 3 карточки. При меньшем количестве возвращается причина, без искусственного добивания результатов.

## Объяснения

Без OPENAI_API_KEY: индивидуальный фрагмент описания + проверенные условия; источник `rules`. С ключом — существующая OpenAI-интеграция; источник `openai`, либо `fallback` при ошибке/дедлайне. SDK timeout 4.5 с, без повторов; внешний async deadline 6 с на объяснение; три карточки запускаются параллельно и возвращаются в порядке ranking. Это не гарантия latency под любой нагрузкой. Порядок карточек детерминирован, текст внешней LLM — не обязательно.

Настройка — копия `.env.example` в `.env`, который загружается явно из папки backend. Модель задаёт `OPENAI_EXPLAIN_MODEL`. Не коммитьте ключ; наружу он не отдаётся. NVIDIA backend отдельно не добавлялся. Реальный платный API при подготовке не проверялся.

Для собственного frontend-домена добавьте его точный origin в `CORS_ORIGINS`. Локальные localhost/127.0.0.1 разрешены. CORS не является аутентификацией; текущий сервер для локального демо, не защищённый публичный SaaS.
