# Shabyt — люди для вашего события

Обновлённый проект на основе загруженного архива `hack-e68c7bd2-triple-a-main (2).zip`.
Это исходники работающего интерфейса и API, а не только дизайн-макет. Фильтрация и ранжирование остаются детерминированными. Отдельно отбираются максимум три карточки, отдельно формируется объяснение.

## Быстрый запуск в Windows

Распакуйте архив в **новую папку целиком**. Не переносите поверх него старый `backend_fixed.zip`, старые `node_modules`, `.venv` или `dist`.
Остановите старые серверы через `Ctrl+C`, особенно процесс на порту 8000.

Нужны Python **3.11+** и Node.js в диапазоне из `frontend/package.json` (`^20.19.0 || >=22.12.0`). Первой установке требуется интернет для npm/PyPI.

В корне проекта запустите двойным щелчком `START_WINDOWS.bat` или в PowerShell:

```powershell
.\START_WINDOWS.bat
```

Скрипт создаёт отдельное Python-окружение, устанавливает зависимости, запускает TypeScript-проверку и Vite-сборку, затем поднимает FastAPI. Откройте после сообщения `Uvicorn running`:

```text
http://127.0.0.1:8000/
```

**На этом адресе будет сайт, не только API.** Сервер раздаёт `frontend/dist`, а `/api/search` обслуживает поиск. Скрипт намеренно собирает режим `api` с базовым путём `/`. Он останавливается на ошибке, а не запускает старую сборку. Окно сервера оставьте открытым; остановка — `Ctrl+C`.

API-ключи не нужны: без ключа объяснения формируются по фактам профиля и обозначаются как «По данным профиля».
Windows-скрипты подготовлены, но в среде проверки Windows не запускались. Ограничения проверки — в `QA_REPORT.md`.

## Что попробовать на сайте

Над формой находятся три кнопки: **«Свадьба в Алматы»**, **«Редкая категория»**, **«Без совпадений»**. Они не показывают заготовленный ответ, а заполняют форму и отправляют запрос в выбранный движок поиска.

Для стандартного датасета: первая выдаёт три фотографа; вторая — одного флориста с явной синтетической меткой и причиной, почему карточек меньше трёх; третья — понятный `no_match`. Для отдельного `no_category` выберите **Астана → Лайв-бэнд**. В том же запросе фотографа поменяйте 14.11.2026 на 15.11.2026, чтобы увидеть влияние календаря.

Доступны все 17 категорий. Цена — «от», не окончательная смета. Календарь только **23.09–31.12.2026**. Профили обезличены; контакты и бронирование не реализованы.

## Режим разработки: два терминала

Первый терминал, из корня, после установки зависимостей:

```powershell
.\backend\.venv\Scripts\python.exe -m uvicorn main:app --app-dir backend --reload --host 127.0.0.1 --port 8000
```

Второй терминал, тоже из корня:

```powershell
cd frontend
npm ci --include=dev
npm run dev
```

Адрес сайта в **этом** режиме — `http://127.0.0.1:4173/`, API — `http://127.0.0.1:8000/docs`.
В данном проекте порт Vite явно задан как **4173**, не 5173. Preview использует **4174**. Всегда сверяйтесь с выводом терминала.
Не открывайте `frontend/index.html` двойным щелчком и не раздавайте исходный `.tsx` обычным файловым сервером: используйте Vite или готовую сборку.

## Проверки

```powershell
.\CHECK_WINDOWS.bat
```

Либо отдельно:

```powershell
.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
.\backend\.venv\Scripts\python.exe -m pytest backend/tests -q
cd frontend
npm ci --include=dev
npm run test:core
npm test
npm run build
```

Реально выполнено при подготовке: **90 pytest-тестов**, **203 проверки ядра frontend**, **46 проверок интерфейса в совместимом браузерном стенде**. Это **не** означает, что полный Vite build/Vitest прошли: npm-реестр был недоступен. Подробная методика и оговорки — `QA_REPORT.md`; исходные логи — `qa/`.

## Необязательные объяснения через LLM

Скопируйте `backend/.env.example` в `backend/.env`, добавьте собственный ключ и перезапустите API. Не публикуйте `.env` и не передавайте ключ во frontend. Используется существующая OpenAI-интеграция, дополненная тайм-аутами и резервным режимом. Реальные внешние запросы при проверке не отправлялись. NVIDIA-интеграция в этот пакет не добавлялась.

## Устройство

```text
backend/         API, валидация датасета, фильтры, ранжирование, объяснения, pytest
frontend/        React + TypeScript + Vite, формы, состояния, темы, browser-catalog
qa/              логи и матрица 150 одинаковых API/catalog запросов
docs/           описание нового дизайна и снимки стенда
START_WINDOWS.bat    установка + сборка + один сервер для сайта и API
CHECK_WINDOWS.bat    локальная проверка backend/frontend/build
```

Основной JSONL — 66 записей, дополнительный — 3; всего 69 уникальных профилей, из них 16 отмечены synthetic. Изменения данных не выполнялись. `frontend/public/data/contractors.json` содержит те же 69 профилей для статического режима.

`npm run build:pages` сохраняет прежний отдельный режим статического каталога для Pages. Он работает без backend и без внешнего LLM, что явно указано в интерфейсе. Не путайте его с обычной API-сборкой.
