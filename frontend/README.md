# Круг — frontend

React + TypeScript + Vite. Сохранены дизайн, тексты и реальный поиск подрядчиков через FastAPI из `../backend`. HTML содержит только оболочку и подключение внешнего модуля; стили и логика находятся в `src`.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
cd frontend
npm install
npm run dev
```

Страница: <http://localhost:4173>. Vite использует фиксированный порт: если он занят, завершите прежний сервер. Прежний `python -m http.server` больше не нужен: он не собирает TypeScript.

Поиск использует существующий бэкенд. В отдельном терминале из корня репозитория:

```sh
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

На Windows окружение активируется через `.venv\Scripts\activate`.

Без ключа OpenAI бэкенд использует свои офлайн-объяснения. Фронтенд не хранит ключи и не заменяет реальные результаты выдуманными: при недоступном API отображается ошибка с повтором поиска.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Vite с обновлением страницы при изменениях |
| `npm run typecheck` | Строгая проверка TypeScript приложения, конфигурации и тестов |
| `npm test` | Тесты API, валидации, сохранения черновика и взаимодействий |
| `npm run test:watch` | Тесты в режиме наблюдения |
| `npm run build` | Проверка типов и production-сборка в `dist` |
| `npm run preview` | Проверка собранной версии на <http://localhost:4174> |

## Рабочие сценарии

- Форма проверяет обязательные поля, допустимые даты и положительные целые числа. Ошибки привязаны к полям, фокус переходит к первому неверному значению.
- Дополнительные пожелания раскрываются; язык и длительность отправляются как `null`, когда не выбраны.
- Запрос отправляется в настоящий `POST /search`. Показываются ровно 1–3 полученные карточки в порядке сервера, объяснение и отметка `synthetic`.
- `no_category` и `no_match` отображаются отдельными штатными состояниями. `message` показывается и при успешной неполной подборке.
- Во время поиска поля блокируются, появляется индикатор и доступна отмена. Тайм-аут — 45 секунд. Поздние ответы отменённого запроса не меняют экран.
- Повтор после ошибки использует параметры последнего запроса, видимые над результатами. Для поиска с изменёнными параметрами используется кнопка формы.
- «Сбросить» очищает поля, результат и сохранённый черновик. Черновик восстанавливается после перезагрузки; недоступный или повреждённый `localStorage` не ломает поиск.
- Навигация переходит к секциям, обновляет активный пункт и работает с историей браузера. Мобильное меню открывается и закрывается кнопкой, Escape, выбором ссылки или нажатием вне шапки.
- Кнопки поддерживают hover, active, focus и disabled. Анимации учитывают `prefers-reduced-motion`.

Карточки — информационные блоки для сравнения; они не изображают ссылки на отсутствующие профили. Бронирование и контакты не входят в контракт API.

## API и окружение

По умолчанию браузер отправляет запрос на `/api/search`. Vite перенаправляет его на `http://127.0.0.1:8000/search`. Этот же proxy работает в `npm run preview`.

Для другого адреса скопируйте `.env.example` в `.env.local` и измените нужное значение:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `API_PROXY_TARGET` | `http://127.0.0.1:8000` | Адрес бэкенда для proxy на стороне Vite |
| `VITE_API_BASE_URL` | `/api` | Адрес API в браузере: путь `/api`, `/` для same-origin `/search` или полный URL |

`VITE_API_BASE_URL=auto` использует хост страницы с портом 8000. Предпочтителен proxy: для доступа из LAN достаточно открыть порт фронтенда. При прямом запросе к другому origin серверу нужен CORS. После изменения `.env.local` перезапустите Vite; переменные `VITE_*` попадают в клиентскую сборку и не должны содержать секреты.

Для production разместите содержимое `dist` на веб-сервере и настройте `/api/*` → backend `/*`, либо задайте доступный `VITE_API_BASE_URL` перед сборкой. Vite dev/preview не является production-сервером.

### Контракт запроса

```json
{
  "city": "Алматы",
  "event_date": "2026-11-14",
  "event_type": "свадьба",
  "category": "Фотограф",
  "budget_kzt": 300000,
  "duration_hours": null,
  "language": null
}
```

Форматы и языки отправляются на русском строчными буквами, как в текущем бэкенде. Даты ограничены заданием: 23.09.2026–31.12.2026. Контракты описаны в `src/types/search.ts`; входящий JSON проверяется во время выполнения, а строки сервера безопасно выводятся React как текст.

## Проверка

Автоматические тесты проверяют числа и границы дат, повреждённый черновик, HTTP/сетевые ошибки, неверный JSON, структуру ответа, отмену и тайм-аут, повтор, оба пустых состояния, синтетические профили, сохранение и сброс формы, навигацию и мобильное меню.

Ручной сценарий для реального backend: Алматы → 14.11.2026 → Свадьба → Фотограф → 300000 ₸. Для пустого результата задайте бюджет 1 ₸; для отсутствующей категории выберите Зарубежье → Флорист. Проверьте также смену параметров, повтор после восстановления API, перезагрузку с черновиком и мобильное меню.
