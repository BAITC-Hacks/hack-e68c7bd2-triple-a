# Frontend Shabyt

React + TypeScript + Vite. Дизайн обновлён в исходниках, темы и API-контракт сохранены. Полная инструкция — корневой README.md.

```powershell
npm ci --include=dev
npm run dev
```

Dev-порт **4173**; `/api/*` проксируется на `127.0.0.1:8000` со снятием префикса. Preview-порт **4174**.

`npm run build` сначала запускает TypeScript typecheck, затем создаёт dist. После сборки FastAPI может раздавать и сайт, и API на 8000; для этого есть корневой START_WINDOWS.bat.

`npm run test:core` — зависимый только от TypeScript набор проверок реальных модулей поиска/валидации/storage, в том числе 150 сравнений с API-фикстурами. `npm test` — полный существующий набор Vitest. `npm run typecheck` — полная проверка типов.

Реально выполнены 203 core checks и синтаксическая транспиляция; полный Vite build/Vitest не подтверждены, так как в среде подготовки npm registry был недоступен. Браузерные проверки совместимости описаны в QA_REPORT.md — они не заменяют запуск с locked dependencies.

`.env.pages` сохраняет автономный browser-catalog режим. `npm run build:pages` использует его без backend/LLM и с явной демо-меткой. Обычный API-режим работает через backend, а не статические ответы.

В интерфейсе все 17 категорий, дата в пределах 23.09–31.12.2026, состояния загрузки/отмены/повтора, защита от устаревшего ответа, сохранение формы с резервным режимом при запрете localStorage, две сортировки и подробности профиля.

Не редактируйте вручную скомпилированный dist. Не переносите node_modules из старого архива. Manrope устанавливается как объявленная npm-зависимость; файлы шрифтов в передаваемый архив не включены.
